# Bundled font

Space Grotesk is hosted locally so the dashboard works without an Internet connection.
Source: https://github.com/google/fonts/tree/main/ofl/spacegrotesk
License: SIL Open Font License 1.1; see OFL-SpaceGrotesk.txt.
The font is a substitute specified by the supplied design reference. Proprietary
PP Neue Machina and Neue Haas fonts are not bundled. Body text uses system fallbacks.
